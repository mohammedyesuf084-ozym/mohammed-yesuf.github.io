# Mohammed Yesuf — Portfolio Website

A responsive, interactive, static portfolio website for GitHub Pages.

## Publish with GitHub Pages (free)

1. Sign in to GitHub as **mohammed-yesuf**.
2. Create a **public** repository named `mohammed-yesuf.github.io`.
3. Upload `index.html` to the repository root and commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment. Your site should appear at:
   https://mohammed-yesuf.github.io/

GitHub documents that Pages can publish from a branch and folder, and that the entry file (such as `index.html`) must be at the top level of the publishing source.

## Update your website

Edit `index.html` in GitHub and commit your changes. GitHub Pages republishes the site after changes are pushed.
